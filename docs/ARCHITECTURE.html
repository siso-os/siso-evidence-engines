SISO Evidence Engines

A Research-section package family for traceable knowledge, credibility-ranked principles, and evidence-gated ideas.

Why one repository first

The three outcomes are distinct, but today they share the same source identity, grounding, provenance, jury, scoring, status, and export primitives. One repository prevents three premature copies. Each engine has a stable machine identity in registry/engines.json and may split without changing its Library identity when independent adoption is real.

Ownership boundaries

Owned hereOwned elsewhere
Evidence schemas, source identities, quote grounding, rubrics, jury aggregation, deterministic scoring, status, exportFoundry discovery, scraping, transcript acquisition, model/provider execution, schedulers, MCP hosting, corpora, databases, generated reports
Idea proposal, rating, and queued statePermission to alter another repository or run an autonomous mutation loop

Evidence first: ungrounded quotes are retained only as rejected records; inferred knowledge must explicitly say it is inferred and carry no fabricated quote. Principles without backing and ideas without evidence cannot enter rating.

Scoring

Principles pass grounded, actionable, general, and not-contradicted gates. Their score is dominated by source credibility and independently identified corroboration; popularity is never read. Ideas pass grounded, novel, right-layer, and not-gameable gates before ROI, effort, and risk arithmetic. Jury votes are stored; deterministic code computes the result.

Evolution

Adapters may acquire and distill sources elsewhere, then submit the explicit JSON contracts. A future split is justified by independent installation, maintainership, consumers, or release cadence—not merely folder size.

Proof

script/test exercises grounded and rejected knowledge, backed and unbacked principles, canonical graduation, backed and unbacked ideas, queued graduation, corpus non-retention, and the publication gate.
